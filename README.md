# Mercado Asegurador Argentino

Proyecto abierto y reproducible para analizar el mercado asegurador
argentino utilizando datos públicos.

## Objetivos

- Descargar datos desde fuentes oficiales.
- Conservar los datos originales.
- Limpiar y estandarizar la información.
- Construir un modelo analítico.
- Documentar las métricas utilizadas.
- Publicar datasets descargables.
- Desarrollar un reporte de Power BI.
- Permitir que cualquier persona reproduzca el pipeline.

## Estructura

- `data/raw`: datos originales.
- `data/processed`: datos procesados.
- `data/sample`: muestras de datos.
- `src`: scripts del pipeline.
- `notebooks`: análisis exploratorio.
- `powerbi`: reporte y modelo semántico.
- `docs`: documentación.
- `outputs`: datasets y controles de calidad.
